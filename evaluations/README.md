# Evaluations
Start with 15 development questions and 15 held-out questions from your manuals. Use questions.template.csv as a header reference; it contains no measured examples.
For each question, record expected evidence or why an answer is unsupported. Define pass/fail criteria for answer support, citations, and appropriate uncertainty.
Use development examples for iteration. Reserve held-out examples for a later frozen comparison, not repeated tuning.
Keep private traces in ignored evaluations/traces/ or evaluations/private/. Label model/prompt/document versions in reviewed result summaries.
